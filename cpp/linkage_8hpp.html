Add selectivity offsets, by fleet, sex and year, to one of five arrays.

Offsets are per fleet; fleets sharing a Selectivity_index still share one parameter block through the map. The param code (RCEATTLE_SEL_*, above) picks the array: slopes slp_offset, inflections inf_offset, non-parametric coefficients coff_offset (every bin), apical height apical_offset, and DoubleNormalSS3 P1-P6 (SS3 pattern 24) dn6_offset.

Parameters
slp_offset[in,out] Slope offsets [2, n_flt, max_sex, nyrs].
inf_offset[in,out] Inflection offsets [2, n_flt, max_sex, nyrs].
coff_offset[in,out] Nonparametric offsets [n_flt, max_sex, n_sel_bins, nyrs].
apical_offset[in,out] Apical-height offsets [n_flt, max_sex, nyrs].
dn6_offset[in,out] DoubleNormalSS3 offsets [6, n_flt, max_sex, nyrs].
link_code,ltSee the note above.

template<class Type>
void rceattle_re_group_nll ( int structure,
vector< Type > re,
Type sigma,
Type rho,
Type & nll,
Type & nll_unweighted )

Add the negative log density of one group's deviations to two accumulators.

RCEATTLE_RE_IID: sd sigma. RCEATTLE_RE_RW: sd sigma on first differences (the first deviation has no term of its own; build_map() holds it at its start, 0 by default, so the base parameter carries the level). RCEATTLE_RE_AR1: stationary, MARGINAL sd sigma and correlation rho (the glmmTMB / Rogers QAR1 convention).

Parameters
structureRCEATTLE_RE_IID, RCEATTLE_RE_RW or RCEATTLE_RE_AR1.
reThe group's deviations, in time order.
sigmaThe group's sd, natural scale (AR1: the marginal sd).
rhoThe AR1 correlation in (-1, 1); read only under RCEATTLE_RE_AR1.
nll,nll_unweightedCells of jnll_comp and unweighted_jnll_comp to add to.
