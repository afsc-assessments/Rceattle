Calculates the historic daily and annual ration for predators.

This function calculates the amount of food consumed by a predator of a specific age and sex in a given year. It updates both the consumption_at_age and ration arrays in place. It supports either full bioenergetics equations (Ceq < 4) or direct empirical input of annual ration (Ceq == 4).

Parameters
consumption_at_ageArray updated with individual consumption (kg/yr) [nspp, max_sex, max_age, nyrs].
nsppTotal number of species in the model.
nyrsTotal number of years (hindcast + forecast).
nyrs_hindNumber of years in the hindcast period.
nsexVector containing the number of sexes modeled for each species.
nagesVector containing the number of age classes for each species.
CeqVector specifying the consumption equation type for each species.
CAVector of intercepts for the allometric mass function (Cmax = CA * W^(1+CB)).
CBVector of slopes for the allometric mass function.
fdayVector of the number of foraging days per year for each species.
PvalueVector of the proportion of maximum consumption (scales Cmax).
fTMatrix of the temperature-dependence function [nspp, nyrs].
ration_dataArray of empirical relative-foraging rates or input ration limits.
weight_hatArray of estimated weight-at-age [n_wt_indices, max_sex, max_age, nyrs].

Calculates the temperature-dependent function of consumption (fT) for bioenergetics.

Updates the fT matrix in place. Supports multiple bioenergetics models: 1 = Exponential function (Stewart et al. 1983) 2 = Warm-water species temperature dependence (Kitchell et al. 1977) 3 = Cool/cold-water species temperature dependence (Thornton and Lessem 1979) 4 = Constant (fT = 1.0)

Parameters
fTMatrix of temperature functions to be updated [nspp, nyrs].
nsppNumber of species.
nyrsNumber of years.
CeqVector specifying which consumption equation to use for each species.
CindexVector specifying which environmental index drives each species.
QcBioenergetics parameter (QC value / intercept).
TcmBioenergetics parameter (Thermal max).
TcoBioenergetics parameter (Thermal optimum).
TclBioenergetics parameter (Thermal limit for Thornton/Lessem).
CK1Bioenergetics parameter (Ascending limit for Thornton/Lessem).
CK4Bioenergetics parameter (Descending limit for Thornton/Lessem).
env_indexMatrix of environmental predictors (e.g., bottom temperature) [nyrs, n_indices].
