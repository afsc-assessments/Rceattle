Parses empirical diet observations and maps them into a 5D proportion array.

  • This function takes the raw diet observation matrix (diet_obs) and its corresponding control matrix (diet_ctl) and maps the observed proportions into the structured 5D diet_prop array for MSVPA based suitability. It dynamically handles indexing for 1-sex versus 2-sex models. If the control matrix specifies a year flt_yr == 0, the observed proportion is applied as an average across all modeled years. Data rows missing specific predator or prey ages are skipped during this step.
  • Parameters
    nsppNumber of modeled species.
    nyrsTotal number of years in the model (hindcast + projection).
    nyrs_hindNumber of years in the hindcast period.
    styrThe starting year of the model.
    minageVector containing the minimum modeled age for each species.
    nsexVector containing the number of sexes modeled for each species (1 or 2).
    diet_obsMatrix of empirical diet observations (column 1 contains the proportions).
    diet_ctlControl matrix mapping each observation row to predator, prey, sexes, ages, and year.
    diet_prop[Output] 5D array (pred_idx, prey_idx, pred_age, prey_age, yr) of observed diet proportions. Modified by reference.

Predicts the expected stomach content proportions given the modeled population state.

  • This function maps the model's internal prediction of diet proportions (diet_prop_hat) back to the structure of the original empirical data (diet_obs). Because empirical stomach data is often aggregated across ages or sexes, this function dynamically calculates the appropriate expected value using abundance-weighted averages (avgN_at_age).
  • It handles four types of data aggregation:
  • Type 1: Specific predator age and specific prey age (weighted across sexes if combined).
  • Type 2: Specific predator age, summed across all prey ages.
  • Type 3: Unweighted arithmetic mean across predator ages, summed across prey ages.
  • Type 4: Abundance-weighted mean across predator ages, summed across prey ages.
  • Parameters
    nsppNumber of modeled species.
    nyrs_hindNumber of years in the hindcast period.
    styrThe starting year of the model.
    suit_styrThe starting year (per predator species) used for suitability averaging.
    suit_endyrThe ending year (per predator species) used for suitability averaging.
    minageVector containing the minimum modeled age for each species.
    nsexVector containing the number of sexes modeled for each species.
    nagesVector containing the maximum number of age bins for each species.
    diet_obsMatrix of empirical diet observations (used here for row-matching).
    diet_ctlControl matrix mapping each observation row to specific aggregation levels.
    avgN_at_age4D array of average population numbers-at-age (used for weighting).
    diet_prop_hat5D array of the model's predicted diet proportions for specific ages/sexes.
    diet_hat[Output] Matrix of predicted diet proportions formatted to match diet_obs. Modified by reference.
