Parses empirical diet observations and maps them into a 5D proportion array.

Maps diet_obs proportions onto the 5D diet_prop array used for MSVPA based suitability, handling 1-sex and 2-sex indexing. A row with flt_yr == 0 is written to every modeled year. Rows aggregated over predator or prey ages are skipped: only diet-data type 1 (a prey age in a predator age) can be used for MSVPA suitability.

Parameters
nsppNumber of species.
nyrsYears, hindcast plus projection.
nyrs_hindYears in the hindcast.
styrFirst year of the model.
minageMinimum modeled age per species.
nsexSexes modelled per species: 1 = combined, 2 = both.
diet_obsDiet observations; column 0 sample size, column 1 the proportion.
diet_ctlMaps each observation row to predator, prey, sexes, ages, and year.
diet_prop[Output] Observed diet proportions (pred_idx, prey_idx, pred_age, prey_age, yr). Modified by reference.

Expected stomach content proportions given the modeled population state.

Maps diet_prop_hat back onto the rows of the empirical diet_obs, which are often aggregated over ages or sexes. The four diet-data types, as the ages encode them:

  • Type 1: Specific predator age and prey age (weighted across sexes if combined).
  • Type 2: Specific predator age, summed across all prey ages.
  • Type 3: Unweighted mean over predator ages, summed over prey ages (r_age > -500).
  • Type 4: As Type 3, but weighted by predator numbers-at-age (r_age < -500).
