Detailed Description

template<class Type>
struct LinkageTable< Type >

The linkage table: one entry per row, and the shared design matrix.

Holds references (to the DATA_ vectors and beta_linkage_eff), so building one copies nothing. Stratum ids are 1-based, with 0 meaning "every level".
