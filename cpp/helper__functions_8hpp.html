template<class Type>
Type concentrated_lognormal_sd ( Type mean_sq_resid,
Type bias_adjust )

Concentrated (analytical) sd of a lognormal observation likelihood.

Catch and index observations are fit as log(obs) ~ N(log(pred) - b * sigma^2 / 2, sigma), with b the bias-adjustment flag bias_adjust_obs (1 = mean-unbiased predictions, Rceattle's default; 0 = median-unbiased). Minimising that density over sigma with S = mean squared log residual gives

sigma^2 = 2 * S / (sqrt(1 + b^2 * S) + 1)

the Walters and Ludwig (1994) estimator sigma = sqrt(S) at b = 0, shrunk as the bias term takes up part of the residual. It is the rationalised form of 2 (sqrt(1 + b^2 S) - 1) / b^2, which needs no branch at b = 0 and stays accurate for small b, where that expression cancels to zero.

Parameters
mean_sq_residS, the mean of squared log(obs) - log(pred).
bias_adjustb, the bias-adjustment flag applied by the density.
Returns
The sd that minimises the lognormal negative log-likelihood.

Construct a sparse GMRF precision matrix separable along year, age, and cohort.

Builds Q = (I - B^T) * Omega * (I - B), where B carries the partial correlation to each neighbouring node and Omega is the diagonal precision (1 / variance). Var_Param selects the conditional (0) or marginal (1) variance parameterization of the GMRF.

The sole caller reads these names the other way round: ceattle.cpp's 3D-AR1 selectivity passes its (bin, year, cohort) correlations in and fills ay_Index as (bin, year), so the two inversions cancel. Read the note at that call before renaming anything here.

Parameters
n_yearsNumber of years.
n_agesNumber of ages.
ay_Index[total_n x 2] age/year index locating each node.
rho_yPartial correlation to the node one back in ay_Index column 0.
rho_aPartial correlation to the node one back in column 1.
rho_cPartial correlation to the node one back in both – the diagonal, which is the cohort when the columns are filled (age, year).
log_sigma2Log variance parameter governing the GMRF.
Var_Param0 = conditional variance, 1 = marginal variance.
Returns
Sparse precision matrix [total_n x total_n], total_n = n_years * n_ages.

◆ log_mean_exp()

template<class Type>
Type log_mean_exp ( const vector< Type > & x)

log(mean(exp(x))) over a non-empty vector, computed so it cannot overflow.

The non-parametric selectivity forms rescale their log-scale coefficients against log(mean(exp(coefficients))) once a year, holding a curve whose level is otherwise unidentified at mean selectivity 1. Summed directly, exp() overflows to infinity once a coefficient passes about 709, the largest argument it takes in double precision, and the objective is NaN thereafter. Subtracting the largest coefficient first holds every exponent at or below 0; the shift cancels out of both the result and its derivative.

Parameters
xnon-empty vector of log-scale values.
Returns
log of the mean of exp(x).
