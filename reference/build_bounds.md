# Build parameter bounds

Function to build parameter bounds based on Holsman et al 2015 and
Kinzey and Punt 2010

## Usage

``` r
build_bounds(param_list = NULL, data_list)
```

## Arguments

- param_list:

  Parameter list object built from
  [`build_params`](https://afsc-assessments.github.io/Rceattle/reference/build_params.md)

- data_list:

  a Rceattle data object

## Value

List of upper and lower bounds
