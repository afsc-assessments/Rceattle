# Fitted multispecies CEATTLE model for the Eastern Bering Sea

A fitted `Rceattle` model object for the multispecies run of CEATTLE for
the Eastern Bering Sea (walleye pollock, Pacific cod, arrowtooth
flounder).

## Usage

``` r
EBS_ms_run
```

## Format

An object of class `Rceattle`.

## Source

Fit by Rceattle to the 2017 Eastern Bering Sea CEATTLE inputs; see
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md)
for their source.
