# Fitted single-species CEATTLE model with estimated M for the Eastern Bering Sea

A fitted `Rceattle` model object for the single-species run of CEATTLE
for the Eastern Bering Sea with natural mortality estimated.

## Usage

``` r
EBS_ss_M_run
```

## Format

An object of class `Rceattle`.

## Source

Fit by Rceattle to the 2017 Eastern Bering Sea CEATTLE inputs; see
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md)
for their source.
