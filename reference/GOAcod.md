# Data inputs for Gulf of Alaska Pacific cod CEATTLE model

A data list containing inputs for a single-species CEATTLE model fit to
Gulf of Alaska Pacific cod data. See
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md)
for format details.

## Usage

``` r
GOAcod
```

## Format

A list with the same structure as
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md).
