# Data inputs for Atka mackerel CEATTLE model (2022)

A data list containing inputs for a single-species CEATTLE model fit to
Bering Sea and Aleutian Islands Atka mackerel data through 2022. See
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md)
for format details.

## Usage

``` r
Atka2022
```

## Format

A list with the same structure as
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md).

## Source

The 2022 assessment, set up in CEATTLE (not the operational model):
Lowe, S., and Ianelli, J. 2022. Assessment of the Atka mackerel stock in
the Bering Sea and Aleutian Islands. In: Stock assessment and fishery
evaluation report for the groundfish resources of the Bering
Sea/Aleutian Islands regions. North Pacific Fishery Management Council,
Anchorage, AK.
