# String\<-\>integer mapping for `M1_re` in [`build_M1()`](https://afsc-assessments.github.io/Rceattle/reference/build_M1.md)

Either form is accepted by
[`build_M1()`](https://afsc-assessments.github.io/Rceattle/reference/build_M1.md);
the canonical integer code is what the TMB template ultimately consumes.
The env-driven options (4, 5) on M1_model can also be expressed through
the `linkages` argument to
[`build_M1()`](https://afsc-assessments.github.io/Rceattle/reference/build_M1.md);
the integer codes continue to work for backwards compatibility.

## Usage

``` r
.M1_RES
```
