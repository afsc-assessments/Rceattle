# Data inputs for a single-species Gulf of Alaska CEATTLE model (2018)

A data list containing inputs for a single-species CEATTLE model fit to
Gulf of Alaska groundfish data through 2018. See
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md)
for format details.

## Usage

``` r
GOA2018SS
```

## Format

A list with the same structure as
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md).

## Source

The single-species models of Adams et al. (2022, Fisheries Research 251:
106303), set up in CEATTLE from the assessments cited in
[`GOApollock`](https://afsc-assessments.github.io/Rceattle/reference/GOApollock.md),
[`GOAcod`](https://afsc-assessments.github.io/Rceattle/reference/GOAcod.md)
and
[`GOAatf`](https://afsc-assessments.github.io/Rceattle/reference/GOAatf.md)
(arrowtooth from the 2017 model).
