# Data inputs for Gulf of Alaska arrowtooth flounder CEATTLE model

A data list containing inputs for a single-species CEATTLE model fit to
Gulf of Alaska arrowtooth flounder data. See
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md)
for format details.

## Usage

``` r
GOAatf
```

## Format

A list with the same structure as
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md).

## Source

The 2017 assessment model, as carried into the 2018 SAFE, set up in
CEATTLE (not the operational model): Spies, I., Aydin, K., Ianelli,
J.N., and Palsson, W. 2017, and Spies, I., and Palsson, W. 2018.
Assessment of the arrowtooth flounder stock in the Gulf of Alaska. In:
Stock assessment and fishery evaluation report for the groundfish
resources of the Gulf of Alaska. North Pacific Fishery Management
Council, Anchorage, AK.
