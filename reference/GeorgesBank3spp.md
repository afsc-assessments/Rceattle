# Data inputs for a three-species Georges Bank CEATTLE model

A data list containing inputs for a multispecies CEATTLE model fit to
Atlantic cod, silver hake and Atlantic herring on Georges Bank,
1978-2007. See
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md)
for format details.

## Usage

``` r
GeorgesBank3spp
```

## Format

A list with the same structure as
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md).

## Source

A CEATTLE recreation of the multispecies statistical catch-at-age model
of Curti, K.L., Collie, J.S., Legault, C.M., and Link, J.S. 2013.
Evaluating the performance of a multispecies statistical catch-at-age
model. Canadian Journal of Fisheries and Aquatic Sciences 70: 470-484.
