# Data inputs for Gulf of Alaska arrowtooth flounder CEATTLE model (2023)

A data list containing inputs for a single-species CEATTLE model fit to
Gulf of Alaska arrowtooth flounder data through 2023. See
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md)
for format details.

## Usage

``` r
GOAatf2023
```

## Format

A list with the same structure as
[`BS2017SS`](https://afsc-assessments.github.io/Rceattle/reference/BS2017SS.md).

## Source

The 2021 assessment model, as carried into the 2023 SAFE, set up in
CEATTLE (not the operational model): Shotwell, S.K., Spies, I., Ianelli,
J.N., Aydin, K., Hanselman, D.H., Palsson, W., Siwicke, K., Sullivan,
J., and Yasumiishi, E. 2021, and Shotwell, S.K., Hanselman, D.H., von
Szalay, P., and Williams, B.C. 2023. Assessment of the arrowtooth
flounder stock in the Gulf of Alaska. In: Stock assessment and fishery
evaluation report for the groundfish resources of the Gulf of Alaska.
North Pacific Fishery Management Council, Anchorage, AK.
